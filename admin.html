Данные и GitHub

Все товары, фото, видео и настройки хранятся в репозитории github.com/donaldpodnebesniy-max/xanut, а не в этом браузере.

🔑 Токен доступа к GitHub

Чтобы панель могла сохранять изменения в репозиторий, нужен персональный токен GitHub (Personal Access Token) с правом записи в этот репозиторий. Читать сайт можно и без токена — он нужен только для сохранения.

⚠️ Репозиторий публичный. Не используйте общий токен со всеми правами — создайте fine-grained токен на GitHub (Settings → Developer settings → Fine-grained tokens), ограниченный только репозиторием xanut и правом Contents: Read and write. Токен хранится только в этом браузере (localStorage/sessionStorage) — в сам репозиторий он не попадает. Но помните: любой, у кого есть доступ к этому браузеру/устройству, сможет им воспользоваться, а сам JSON с настройками (в т.ч. хеш пароля) виден всем в публичном репозитории — не храните здесь ничего секретнее, чем контент сайта.
